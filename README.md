# AI Article Writer

A powerful local AI article generator that uses OpenCode Big Pickle, Gemini, Mistral, or OpenAI to create human-style, SEO-optimized blog articles with image prompts.

## Quick Start

### Requirements
- [Node.js](https://nodejs.org) (LTS version)

### Run the App

1. Download this project as a ZIP from GitHub (green **Code** button → **Download ZIP**)
2. Extract the ZIP anywhere on your PC
3. Double-click **`start.bat`**
4. The app opens in your browser automatically at `http://localhost:XXXX`

> **First run only:** The bat file will automatically install dependencies (~30 seconds). After that, it starts instantly.

## API Keys (Pre-Configured)

The following API keys are already built into the app:

| Provider | Key | Model |
|---|---|---|
| **OpenCode** | Pre-filled | Big Pickle (Reasoning) — Best quality |
| **Mistral** | Add your own | For fast image prompts |
| **Gemini** | Add your own | Fast & free |

You can change any API key from the sidebar Settings panel.

---

## Features

- **Anti-Skeleton V8.6** writing mode — produces natural, human-style content
- **30 Hairstyle Listicle** mode — Pinterest-ready formatted articles
- **Blog + Pinterest image prompts** — generated automatically
- **SEO meta** — title and description generated for each article
- **ZIP download** — article + prompts + SEO packed into one file
- **Multi-website support** — switch between TressAtlas and TressCrew
- **Batch generation** — run multiple keywords at once
- **Supabase sync** — articles saved to database

---

## Stopping the App

Close the black command window (titled "AI Article Writer") to stop the server.
